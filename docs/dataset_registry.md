# Dataset Registry

This project uses three datasets from the UCI Machine Learning Repository.

## 1. Breast Cancer Wisconsin (Diagnostic)

- UCI ID: 17
- Dataset name: Breast Cancer Wisconsin (Diagnostic)
- Instances: 569
- Features: 30
- Task: Binary classification
- Feature type: Real
- Primary metric: ROC-AUC
- License: CC BY 4.0
- DOI: 10.24432/C5DW2B
- Official source:
  https://archive.ics.uci.edu/dataset/17/breast

## 2. Adult

- UCI ID: 2
- Dataset name: Adult
- Instances: 48,842
- Features: 14
- Task: Binary classification
- Feature types: Categorical and Integer
- Missing values: Yes
- Primary metric: PR-AUC
- License: CC BY 4.0
- DOI: 10.24432/C5XW20
- Official source:
  https://archive.ics.uci.edu/dataset/2/adult

## 3. Bank Marketing

- UCI ID: 222
- Dataset name: Bank Marketing
- Instances: 45,211
- Input features: 16
- Task: Binary classification
- Target: y
- Primary metric: PR-AUC
- License: CC BY 4.0
- DOI: 10.24432/C5K306
- Official source:
  https://archive.ics.uci.edu/dataset/222/bank+marketing

## Data policy

Raw datasets are not committed to the Git repository.

The download date, source, dataset version, and SHA-256 checksum should be recorded after acquisition.
